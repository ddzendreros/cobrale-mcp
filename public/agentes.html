El problema

Cobrar con CoDi debería ser tan fácil como pedirlo.

CoDi es gratis y el pago llega en segundos. La integración técnica todavía deja fuera a muchos negocios y equipos.

01 · EL PAGO YA EXISTE

CoDi funciona desde la app bancaria de quien paga.

02 · FALTA LA CONEXIÓN

Un negocio necesita código, webhooks y seguimiento para enterarse del pago.

03 · EL AGENTE PUEDE COBRAR

Cóbrale ofrece herramientas MCP para que el agente cree y confirme el cobro.

Conéctalo en 1 minuto

Tu agente ya sabe qué hacer. Dale una forma de cobrar.

Usa el endpoint de este mismo servidor en Codex o en una integración con Responses API.

URL del servidor MCPhttps://tu-dominio/mcp

Con Codex

Agrega Cóbrale como servidor MCP remoto. El comando y la configuración usan la URL de esta página.

Terminal
codex mcp add cobrale --url https://tu-dominio/mcp
config.toml
[mcp_servers.cobrale]
url = "https://tu-dominio/mcp"
tool_timeout_sec = 300

Este servidor pide token: pídeselo al equipo y define PEY_MCP_TOKEN en el entorno de Codex.

Con Responses API

Incluye el servidor MCP remoto en la solicitud de Responses y deja que el agente use sus herramientas.

JavaScript
const respuesta = await client.responses.create({
  model: "gpt-6-astra",
  input: "Cóbrale $1,250 por FAC-001 y avísame cuando pague.",
  tools: [{
    type: "mcp",
    server_label: "cobrale",
    server_url: "https://tu-dominio/mcp",
    authorization: process.env.PEY_MCP_TOKEN,
    require_approval: "always"
  }]
});

Si el servidor pide token, define PEY_MCP_TOKEN en tu entorno de servidor. No pegues la clave en código público.

Herramientas MCP

Lo necesario para cobrar y confirmar.

El agente puede crear el cobro con el método adecuado, esperar el resultado y revisar pagos recientes.

HerramientaQué hace
cobrar_con_qrCrea un cobro CoDi y devuelve el QR para escanear desde la app bancaria.
cobrar_a_celularEnvía una solicitud de pago CoDi al celular registrado en el banco.
crear_link_de_pagoGenera un checkout para compartir por chat, correo o WhatsApp.
esperar_pagoEspera la confirmación o el tiempo límite; se usa después de crear un cobro.
estado_del_cobroConsulta si un cobro está pendiente, pagado o cancelado.
pagos_recibidosLista cobros pagados recientemente por agentes o desde Libreta.
cancelar_cobroCancela un cobro pendiente en Cóbrale.

Recurso MCP

cobrale://pagos/hoy

Pagos confirmados desde la medianoche local y el total del día.
